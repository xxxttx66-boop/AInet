# 自定义实验

2026-10-15。按已确认需求实现完整拓扑编辑；AI 只读取学员命令与输出、提供指导。继续沿用单人实验环境。

## 学员流程

1. 学习首页或侧栏进入「自定义实验」，填写名称并选择在线 eNSP Pro 环境。
2. 创建空白沙箱后，按模拟器返回的型号添加设备，拖动位置，从两端接口创建连线。
3. 点击设备可查看接口、启动或停止设备、删除设备。增删连线及删除设备前必须停止涉及的设备。
4. 点击「进入实验工作台」，使用已有拓扑、终端与 AI 面板；「返回自定义实验」回到该沙箱编辑页。
5. 删除实验须先停止全部设备，并确认删除；同时删除模拟器沙箱、AInet 登记和该实验的 AI 对话。

界面显示沙箱拓扑数量上限及当前环境同时运行设备上限。启动过程继续使用既有看门狗、容量约束和初始化检查。

## 归属与运行上下文

- `custom_labs` 保存创建者、环境 key、模拟器 sandbox ID、显示名称。模拟器中的名称使用独立随机前缀，避免与课程拓扑重名。
- 编辑接口只操作当前学员登记的自建沙箱，并重新核对当前选中的环境 / 沙箱。现有课程、考试沙箱不提供登记或编辑入口。
- 拓扑修改与环境切换使用相同的锁顺序：环境锁、考试锁、练习锁。练习、考试或环境准备中拒绝编辑。
- eNSP Pro REST 登录客户端由环境上下文共享。切换遵循既有停机规则；不增加新的模拟器登录会话。
- 删除沙箱后释放其后台看门狗、空闲计时器、console 和持久化运行状态，保留同环境其他沙箱及共享 REST 会话。
- 当前仍是单人部署；数据库归属检查不代表支持多个学员同时运行独立工作台。

## AI 上下文

服务端在每次提问时生成当前拓扑、设备状态、连线、最近最多 15 条命令与输出摘要。总字符数继续受现有上限约束，长输出保留首尾并标记省略。

自定义实验使用 `custom:<实验 ID>` 保存和读取对话，服务端不接纳客户端传来的其他实验历史。环境切换清空终端采集记录；提问组装时发生切换则要求重新提问。自定义实验不向模型提供命令执行工具，页面显示本次附带的命令数量。练习对话仍以 `practice:<attempt ID>` 区分，考试继续禁止 AI。

## 页面与接口

- 页面：`GET /custom-labs`；工作台链接携带自定义实验 ID 与环境 / 沙箱标识。
- `GET|POST /api/custom-labs`：列出自己的实验、创建新实验。
- `POST /api/custom-labs/{id}/activate`：选中实验；`GET /api/custom-labs/{id}`：拓扑与状态。
- `GET /api/custom-labs/{id}/models`：当前环境提供的设备型号。
- `POST /api/custom-labs/{id}/devices`：添加；`PATCH|DELETE /api/custom-labs/{id}/devices/{device}`：移动、删除。
- `POST /api/custom-labs/{id}/links`、`DELETE /api/custom-labs/{id}/links/{link}`：创建、删除连线。
- `DELETE /api/custom-labs/{id}`：删除沙箱及登记。设备启停复用已有 `/api/lab/devices/{action}`。

## 检查记录

- 临时库与内存模拟器覆盖创建、移动、端口归属和占用、运行保护、删除、学员归属与切换竞态。
- Agent 回归覆盖不提供执行工具、当前沙箱命令及输出、隔离其他沙箱与客户端历史、练习对话标识。
- 浏览器使用拦截的演示数据完成创建、添加、拖动、连线及连续两次 AI 提问；1440px 与 390px 页面无脚本异常，手机无横向溢出。
- 真实 eNSP Pro 上仅使用临时、未启动的自建沙箱验证创建、型号、两台设备、连线、移动、删除；完成后清理临时沙箱并恢复 AInet REST 会话。核对原沙箱设备状态、位置和连线未变。
- 本轮未在新建实验中启动真实设备、执行真实终端配置或调用付费 AI；这些能力沿用现有工作台链路。
