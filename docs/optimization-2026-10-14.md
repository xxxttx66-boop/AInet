## 2. 设备与考试流程

| 问题 | 本轮处理 |
| --- | --- |
| 手动重登返回成功但服务会话未恢复 | 清除旧 SSO cookie，验证模拟器服务接口，重建使用旧会话的终端连接；旧请求的失效响应不会覆盖已成功的新登录 |
| console 自动重登时丢失输入 | 输入暂存，成功后按顺序发送；不会进入密码提示；转发失败时明确关闭连接 |
| 已有 start_failed 状态导致准备失败 | 原代码已有首次准备时的恢复路径；补上普通失败重新启动和慢设备已上线两种回归，更新旧交接说明 |
| 后台任务只跟踪当前环境，设备编号跨实例冲突 | 按环境 / 沙箱保留独立看门狗、空闲计时器和后台 console；停机时间按环境隔离；同环境沙箱共享 REST 客户端 |
| 多题考试只在开考时检查容量 | 在每次开始一道题时检查容量，覆盖下一题、重试和单题考试 |
| 经典版进程已启动但 console 仍在启动 | 在建立练习记录与修改配置前检查提示符；未就绪返回可重试的 busy；准备流程等待提示符 |

新运行状态存为 `lab:power:<环境>:<沙箱>`；服务启动恢复所有有效上下文，并兼容旧 `lab:power`。修改地址或删除环境会释放该环境全部旧上下文；更新设备密码会清除其各沙箱的旧认证失败记录。
