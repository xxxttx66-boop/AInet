自由问答
AR2 的 GE0/0/0 连到哪台设备？路由表里有去 PC1 网段的路由吗？
已在 AR2 执行（只读）：display ip routing-table
GE0/0/0 连到 AR1 的 GE0/0/2（来自拓扑）。
AR2 路由表里有 192.168.10.0/24（直连），PC1 就在这个网段，所以从 AR2 能到 PC1。
LoopBack0 后面的 up(s) 是什么意思？
(s) 表示 spoofing：环回口和 NULL0 这类逻辑接口没有物理链路，协议状态始终显示 up，所以标了 (s)。
