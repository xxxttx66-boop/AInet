# AInet 界面升级

2026-10-14，按用户选择采用「学习训练平台」整体结构，实验区采用「专业实验台」的大终端布局。
本文件取代 `ui-layout.html` 的历史布局约定；选题、环境准备、考试限制及设备操作规则继续沿用。

## 共享界面

- 本地 `frontend/ui.js` 提供平台导航、主题切换和 SVG 图标，`ui.css` 提供共享视觉及布局。
- 主导航：课程中心、实验工作台、学习记录；次级入口：考试模板、环境设置、AI 设置。
- 工作台默认收起导航，保留图标与可访问名称；课程和记录默认展开。导航偏好存 `ainet.ui.navCollapsed`。
- 默认浅色主题，可切换深色，偏好存 `ainet.ui.theme`。终端始终使用深色背景和明确前景色。
- 图标源随源码保存，不需要外部图标库或 CDN。按钮动态更新文字时图标通过 CSS mask 保留，主要操作同时有文字标签。
- 页面脚本保留原有 DOM ID；导航、样式和图标共享，实验操作仍由 app.js / exam.js 等处理。
- 所有资源及链接使用相对路径，包含嵌套的 exam 页面。后端静态文件白名单增加 ui.js / ui.css。

## 课程中心

- 首页打开后先看到环境选择卡片，随后是章节；选题后，练习 / 自由实验 / 考试入口在课题列表之前显示。
- 环境显示顺序为用户添加的 eNSP Pro 实例、内置 eNSP Pro、经典 eNSP。
- 环境卡片使用等宽网格；已通过课题仍可重复练习，入口标为「再次练习」，每次生成独立记录。
- 首页环境区只负责浏览和选择课程环境；「环境设置」进入独立页面，集中展示地址、凭据、连接探测、容量、看门狗参数和添加环境入口。设置页读取当前环境状态，不更改课程浏览环境。
- 接入设置在独立页的环境卡片下方展开，保留原有保存、测试、凭据及运行参数操作；展开时环境卡片保持紧凑。
- 预览展示题名、知识点、拓扑、工单与验收目标、准备说明。
- 进入方式用原生单选控件选择练习 / 自由实验 / 考试，显示对应说明及一个主按钮；原有进入处理函数与后端接口不变。
- 多题考试模板使用原有开始考试按钮；不展示单题进入方式。准备时禁用进入方式选择。
- 学习记录的「再次练习」链接带场景 ID 和平台；进入课程时优先选择同平台可用环境、对应章节与课题。
- 浏览环境和选题不切换实验环境，仍在点击主按钮后准备环境；进行中的练习、考试与复位继续阻止开题。

## 实验与考试

- 题名、环境摘要、学员菜单与退出放在第一行；模式、计时、检查、提交等操作放在第二行。
- 拓扑默认宽 220px，工单 / Agent 默认宽 300px；已有手动宽度偏好继续生效。两侧仍可拖动与收起。
- 新增「专注终端」：暂存当前两侧折叠状态并收起，再次点击恢复；不切换模式或操作设备。
- 按实际工作区宽度选择侧栏抽屉，导航展开 / 收起也会触发重新计算。
- 700px 以下双终端上下排列，避免两块最小宽度终端挤出屏幕；手机首次进入默认收起拓扑。
- 考试作答时保留隐藏右侧 Agent / 工单侧栏、隐藏可受限的环境摘要、模式锁定、退出禁用及交卷确认。
- 考试中工作台的全局导航链接移除 href 并标为不可用，不能借新导航绕过原有退出流程；AI 设置入口隐藏。
- 工作台回课程仍调用已有退出处理，练习中按原流程确认、结束和复位。

## 学习记录与其他页面

- 学习记录显示已完成课题、当前返回的考试记录数和待复习课题数，均来自已有 API 数据。
- 最近练习、考试、掌握度、错题分组显示；学员信息收进可展开区域。
- 错题提供返回课程并预选课题的入口；考试成绩单与命令回放沿用原有真实数据与操作。
- 登录、模板管理、成绩单、AI / 环境设置复用颜色、输入框、按钮、表格和卡片样式。
- 考试模板列表改为响应式卡片，题目与规则分区展示，时长和题数单独成组；编辑、删除及表单控件使用浅色主题样式。
- 新建学员的密码输入使用 password 类型，避免在屏幕上显示明文。

## 本轮检查范围

- 前端脚本、Python 语法及 28 道场景静态校验；GitHub 上使用已有 CI。
- 独立只读预览服务器提供演示数据，用于查看课程、实验工作台、学习记录、模板管理、登录、明暗主题和手机排版。
- 预览未导入设备连接器，POST 被拒绝，console 输出由预览浏览器中的演示对象提供。
- 未启动、停止或修改真实实验设备，未部署运行中的服务。真实设备、考试与 AI 端到端验收需另行安排。
- 首轮 UI 提交的 Windows / Python 3.11 CI 暴露已有取消流用例的竞态：仅等扣分写入便断言回复落库。用例改为等待 Agent 后台收尾任务完成；生产 Agent 实现不变。
